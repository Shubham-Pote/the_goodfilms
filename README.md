# The Good Films

The Good Films is a streaming app where users can watch movies, web series, and live streams in one place.

It is built to feel simple: sign in, discover what to watch, and start streaming quickly.

## What You Can Do

- Create an account and log in securely with JWT-based authentication.
- Browse trending and popular content.
- Search for movies and shows.
- Open a details page before watching.
- Stream movies and web shows from the player page.
- Watch live events from the live section.
- Continue from where you left off with Continue Watching.

## App Experience

### 1. Sign In

Create an account or log in to access the full app.

### 2. Discover Content

Use the home page categories and search to find something to watch.

### 3. View Details

Open any title to check the overview and then start playback.

### 4. Start Streaming

Watch movies and web shows directly from the player.

### 5. Watch Live Streams

Go to Live to join ongoing or upcoming events.

### 6. Continue Watching

Return later and continue from your recent progress.

## Who This App Is For

- Users who want movies, web shows, and live streams in one app.
- Viewers who want a clean and fast watch flow.
- Admin users who need to manage live stream events.

## Run Locally

If you want to run the project on your machine:

1. Install dependencies in both folders:
	- Client
	- Server
2. Add required environment variables.
3. Start backend from Server.
4. Start frontend from Client.

For command-level setup, check the project files inside Client and Server.
